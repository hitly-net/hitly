---
title: Connections
description: Workspace credentials for origin frameworks.
---

A **connection** stores how Hitly reaches an origin:

| Plugin | Credentials |
| --- | --- |
| Mastra | Base URL + API token |
| n8n | Instance URL (resume URLs are per-execution) |
| LangGraph | Deployment URL |
| Temporal | Address, namespace, task queue |

Create connections at `app.hitly.net/settings/connections`. Pass `connectionId` on ingest so resume can load credentials.

API keys (`/settings/api-keys`) authenticate inbound ingest. They are not the same as origin credentials.
